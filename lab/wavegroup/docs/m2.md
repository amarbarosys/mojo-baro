# M2: Llama ops, status

Imported from mojo-baro by include path (`tools/mojo.sh`), never copied:
- elementwise (rmsnorm, swiglu, rope, softmax+argmax, embed): `test_elementwise` PASS, max err <= 1e-6.
- k-quant GEMV (q4_K, q6_K; bf16 or f32 activations): `test_gemv_kq` 0 mismatches.
- Attention: NOT importable. mojo-baro's `attn.mojo` takes its head dims from `serve/model.mojo`, which only knows the Qwen configs.

GEMV bandwidth, Llama 1B decode shapes, weights rotated over 256 MB (`kernels/gemv/bench.mojo`), gate 80% of 960 GB/s:

| N x K | role | us | GB/s | of 960 |
|---|---|---|---|---|
| 128256 x 2048 q6_K | lm head | 285.6 | 755 | 79% |
| 8192 x 2048 | gate, up | 14.5 | 650 | 68% |
| 2048 x 8192 | down | 15.9 | 595 | 62% |
| 2048 x 2048 | q, o | 6.7 | 351 | 37% |

Launch overhead: an empty kernel costs 2.5-2.9 us of device time, so the small shapes are mostly launch.

## Split-K fix (kernels/gemv/gemv_split.mojo, tools/sweep_gemv.sh)

`wg_gemv_kq[S]`: S waves per row, partial sums added in LDS in wave order (deterministic). S=1 is bit-exact with
amar_gemv_kq; S>1 differs by <= 1.1e-4 relative (summation order). Best per decode role, kernel-only share of 960:

| role | shape | best S | us | kernel-only |
|---|---|---|---|---|
| q+k+v (concatenated at load) | 3072 x 2048 | 4 | 8.7 (S=0: 12.0; separate q,k,v ~15) | 62% (S=0: 39%) |
| o | 2048 x 2048 | 0 | 6.3 | 65% |
| gate, up | 8192 x 2048 | 0 | 14.8 each | 81% |
| down | 2048 x 8192 | 0 | 16.0 | 73% |
| lm head q6_K | 128256 x 2048 | 0 | 308-312 (S=2: 334-348) | ~70% |

Split-K wins only at q+k+v and 512 rows; it loses where rows already fill the GPU. S is a per-shape table the planner
holds, not a rule (3072 is slower than 2048 at S=0).

Per token: 16 x 60.6 + 310 = 1.28 ms of GEMV (was 1.39), vs 0.79 ms roofline. Gate (80% kernel-only) passes only for
gate/up. What is left: launches (5 per layer x ~2.6 us = 13 of 60.6 us) and small-N latency. Both point at fewer,
bigger kernels per layer (a persistent decode kernel, mojo-baro `mega.mojo` pattern) or own KFD queues (M5).
