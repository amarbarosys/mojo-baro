## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
An LLM inference engine for AMD RDNA3 GPUs with every GPU kernel written in Mojo. It serves chat over an
OpenAI-compatible HTTP API on one RX 7900 XTX (`tools/baro serve MODEL.gguf`, default port 8080), from
self-describing GGUF bakes that carry their own kernel sources.

## Highlights

- The RegesCore-35B MoE bake (`RegesCore-1.0-35B-UD-Q4_K_S-BARO-7d42feb.gguf`) verifies and serves: `tools/baro serve`
  runs it in tier mode instead of loading the 20 GB resident pack that ran out of VRAM next to the desktop.
- The spark pack build peaks at 0.35 GB of memory instead of 2.60 GB.

## Changes

### Added
- `tools/baro serve` splits the pack into trunk + `experts.bin` and serves the expert tier when a bake's run env sets
  `BARO_TIER` (`5260822`).
- `tools/baro-rebake.sh` takes `BARO_REBAKE_REF` (new reference ids) and `BARO_RUN_ENV` (`5260822`).
### Changed
- The MoE bake's reference ids are the int8 build's own: bake verify checks that a file reproduces its default build,
  which is int8 KV since `f3220ad`. The f32-referenced `e40d9ca` bake keeps failing verify at position 8 (`5260822`).
### Fixed
- `tools/baro-rebake.sh` re-embedded the Python pack tool by its bare name; it now embeds the current tool (`5260822`).
- `tools/spark-pack.mojo` releases each tensor's mapped pages after writing it (`7d42feb`).

## Known limits

- The first `baro serve` of a MoE bake builds the resident pack and then splits it (101 s on RegesCore-35B); both stay in
  the cache (the split uses copy_file_range, so on btrfs they share extents).
- `tools/baro verify` on a MoE bake still needs `BARO_PACK` pointed at a tier pack; it does not build one itself.
- Bake verify compares greedy ids with the file's own default build. It says nothing about int8 against f32; the
  agreement gate (`bench/int8-moe-protocol.md`) does.
