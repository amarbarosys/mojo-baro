## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
An LLM inference engine for AMD RDNA3 GPUs with every GPU kernel written in Mojo. It serves chat over an
OpenAI-compatible HTTP API on one RX 7900 XTX (`tools/baro serve MODEL.gguf`, default port 8080), from
self-describing GGUF bakes that carry their own kernel sources.

## Highlights

<!-- 1 to 5 bullets a user would notice. Lead with the benefit, not the implementation. -->
- Two engines on one GPU share an 8k working memory without a file: `POST /v1/ipc/fork` hands a
  checkpoint from server A to server B over HIP IPC, first token in 88 ms vs 121 ms from the shared file.

## Changes

### Added
- `POST /v1/ipc/fork` (front A relays a 320-byte LatentHeader + IPC handle to B), `POST /v1/ipc/turn`
  (B: header check, 409 on another pack or prefix before any HIP call, GPU-to-GPU ingest, fork),
  `POST /v1/ipc/sha`, `GET /v1/ipc/stats`; engine ops `ipc_export` / `ipc_release` / `ipc_sha` /
  `ipc_stats` (`e2e40b5`, `bf2a2df`); gate `bench/t3b-gate.sh` (`c4d8333`); `BARO_SHIM_LIB` setting.
- Engine startup log prints `seq_cap` (arm read-back).
### Fixed
- IPC export stages are pooled and reused: on ROCm `hipFree` never reclaims an allocation exported with
  `hipIpcGetMemHandle`, so the first build leaked 0.58 GB of VRAM per export (`4855d09`,
  `bench/t3b-ipc-free-probe.c`).

## Known limits

<!-- Honest list: slow paths, unsupported cases, flaky upstreams, anything UNVERIFIED. -->
- Same host and GPU only; f32 KV only; IPC lines go to engine 0 of a pool.
- Two 9B engines fit only when built with `-D BARO_SEQ_CAP=1` (8.8 GB each at `BARO_TMAX=9216`).
- The LatentOS agent as the relay is not built (link 3); claim 1 stays `partial`.

## Upgrade / run

<!-- Exact commands. Migrations, new deps, service restarts, config keys. "None" if nothing changed. -->
```
cmake -S shim -B .work/shim-build && cmake --build .work/shim-build
BARO_SHIM_LIB=$PWD/.work/shim-build/libamarbaro_shim.so serve/target/release/baro-serve --engine ENGINE --pack PACK --port 8260   # A, and B on 8261
curl -X POST localhost:8260/v1/ipc/fork -d '{"checkpoint":"ID","target":"127.0.0.1:8261","suffix":"...","max_tokens":32}'
```
