## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
An LLM inference engine for AMD RDNA3 GPUs with every GPU kernel written in Mojo. It serves chat over an
OpenAI-compatible HTTP API on one RX 7900 XTX (`tools/baro serve MODEL.gguf`, default port 8080), from
self-describing GGUF bakes that carry their own kernel sources.

## Highlights

- The spark engine (Spark-X2.5-4B) builds on Mojo 1.1 again and serves JSON-schema requests: 59 of 66 gate
  requests return valid, schema-matching JSON.

## Changes

### Fixed
- `serve/spark.mojo` compiles on Mojo 1.1 (`512dcd1`).
- The grammar vocabulary loader accepts added special tokens that are not byte-level (spark2_5) (`512dcd1`).
- `tools/spark-pack.py` builds a spark pack straight from a K-quant GGUF (`512dcd1`).

## Known limits

- Spark prints no masked-draw receipt, so grammar gate 4 cannot pass on spark yet.
- On spark-4B, unbounded number fields can run to max_tokens as endless digits (6 of 66).
- Spark with reasoning on can repeat its BOS token while thinking.
