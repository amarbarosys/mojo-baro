# mojo-baro v0.4.0

**Status:** Unreleased · **Previous:** [v0.3.0](v0.3.0.md)

## What changed

- Batched prefill speed gates verified on RX 7900 XTX: 10.1x speedup at 1k (2860 tok/s) and 8.5x at 8k (2395 tok/s).
- MoE attention agreement: 100% agreement (64/64 tokens) across 512, 1024, and 8192 prompt lengths.
- Multi-GPU routing gate: dual-engine token routing bit-exact (20/20 tokens).
- VRAM pool floor clamped to 2% (capped <= 10%) preventing multi-tenant VRAM exhaustion.
- RegesCore hidden-row export captured actual post-final-norm `2048`-wide f32 rows.
- Llama receiver consumed a pinned latent payload with `semantic consume_count=1`.
- Control output changed from token `16309` to `72977` under latent injection.
- Added paired-row capture and NumPy affine training harnesses.
- Added content-addressed manifest rebuild optimization, avoiding repeated `808 MiB + 2.3 GiB` weight hashing.
