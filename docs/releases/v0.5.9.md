## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
An LLM inference engine for AMD RDNA3 GPUs with every GPU kernel written in Mojo. It serves chat over an
OpenAI-compatible HTTP API on one RX 7900 XTX (`tools/baro serve MODEL.gguf`, default port 8080), from
self-describing GGUF bakes that carry their own kernel sources.

## Highlights

<!-- 1 to 5 bullets a user would notice. Lead with the benefit, not the implementation. -->
- 2.03 GB less VRAM per weight copy of the 9B: `BARO_EMBD_HOST=1` keeps the token embedding table in
  host memory, decode 0.997x, outputs bit-identical. With shared weights (v0.5.8) the two-engine pair
  now needs 9.77 GB instead of 18.32.

## Changes

### Added
- `BARO_EMBD_HOST=1`: `token_embd` (bf16, the pack's first tensor) in mapped pinned host memory read
  in place by the embed kernels; VRAM holds the rest of the pack (`a6341b0`).
- `bench/t3b-gate.sh` `T3B_EMBD=host` and `T3B_VRAM_BAR`.
### Changed
- The IPC weight record (v0.5.8) carries device bytes, so engines that disagree on `BARO_EMBD_HOST`
  refuse to pair (size mismatch) instead of mapping a buffer of the wrong length.

## Known limits

<!-- Honest list: slow paths, unsupported cases, flaky upstreams, anything UNVERIFIED. -->
- `realign`'s full-table gather reads all 2.03 GB over PCIe per call with the knob on.
- Each engine pins its own 2.03 GB host copy (host memory is not shared over IPC).
- Dense packs whose first tensor is bf16 `token_embd` only; a tier pack or another layout raises.
- Decode cost measured on 3 prompts x 32 tokens under load 8.21, not the 20-prompt gate.

## Upgrade / run

<!-- Exact commands. Migrations, new deps, service restarts, config keys. "None" if nothing changed. -->
```
BARO_EMBD_HOST=1 baro-serve --engine E --pack P            # any engine
BARO_EMBD_HOST=1 BARO_WEIGHTS_EXPORT=w.rec ...  /  BARO_EMBD_HOST=1 BARO_WEIGHTS_IMPORT=w.rec ...   # a pair: both set it
```
Off by default; no migration.
